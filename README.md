# Plates — starter app

## Run it
1. Unzip this folder and open it in Claude Code (`claude` in the folder, or open the folder in the desktop app).
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Open the local URL it prints (usually http://localhost:5173).

## What's here
- React + Vite + Tailwind CSS v4
- 5 tabs wired up: Browse, Saved, Sell, Chats, You
- Mock data in `src/data/listings.js` — swap this for real API calls later
- Working screens: browse feed, listing detail, post-a-listing form
- Saved / Chats / Profile are placeholders — good next thing to build
